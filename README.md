## Описание проекта

В рамках данного проекта проведён **регрессионный анализ** набора данных *mpg* с целью прогнозирования расхода топлива.

### Ключевые этапы работы

-  Выполнен **разведочный анализ данных** и визуализация ключевых зависимостей.
-  Проведена **предобработка данных**: масштабирование признаков, кодирование категориальных переменных, обработка пропущенных значений.
-  Реализованы **три метода градиентного спуска**: классический, стохастический и мини-батч, с использованием регуляризации **Ridge**.
-  Проведён **подбор гиперпараметров** для минимизации *RMSE*.
-  Оценено качество моделей с использованием метрик **MSE**, **RMSE** и **R²** на обучающей и тестовой выборках.
-  Для **Ridge Regression** применён **GridSearchCV** для оптимизации коэффициента регуляризации.
-  Выполнен **отбор значимых признаков** с помощью *рекурсивного исключения признаков (RFE)*.
-  Использована **кросс-валидация** для проверки устойчивости результатов.

### Результат

Получены и проанализированы модели, демонстрирующие эффективность различных стратегий обучения и регуляризации для задачи прогнозирования показателя *mpg*.
